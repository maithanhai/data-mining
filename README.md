# data-mining
Bài tập lpwns thực hiện quy trình KDD (Knowledge Discovery in Databases) từ con số 0 trên nguồn dữ liệu sống thực tế tại thị trường lao động Việt Nam. Tự động hóa việc thu thập dữ liệu tuyển dụng việc làm CNTT, giải quyết bài toán tiền xử lý văn bản phức tạp, trích xuất kỹ năng, gom cụm phân khúc thị trường và dự báo mức lương/yêu cầu công việc.
